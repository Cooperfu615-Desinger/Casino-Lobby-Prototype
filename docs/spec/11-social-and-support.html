1. 這個功能是什麼

玩家在公共頻道、私人對話與客服輸入訊息，透過玩家卡管理好友、封鎖、贈禮與檢舉。玩家卡顯示其他玩家的示範資料，與第 06 章自己的個人資訊分開。

2. 這個功能不做什麼

不做的事 負責位置
自己會員資料與 VIP 第 06 章
贈禮扣款與計算 第 09 章
正式送達、客服案件與自動發送排程 後續訊息及客服服務

3. 名詞說明

名詞 定義與例子
玩家卡／個人資訊 前者查看他人，後者修改自己；不能互用入口與權限。
對話歸屬／私聊草稿 訊息按對象區分，草稿為私聊共用，不是每個對象各存一份。
好友／封鎖 封鎖不刪好友或舊訊息；解除由設定共用清單承接。
自動發送設定／排程 保存設定與顯示啟用，不代表已開始發訊息。

4. 畫面內容

聊天中心包含三個頻道、對話或好友／玩家目錄、訊息區與輸入列。訊息顯示內容、自身／對方位置及適用的頭像與時間；私聊可開表情選擇與加號選單。客服顯示歡迎訊息，檢舉入口另顯示目標提示。

玩家卡包括帳號、暱稱、VIP、簡述、最近遊玩展示與社交操作；最近遊玩卡片沒有啟動遊戲事件。黑名單列表與解除見 12.5。

5. 欄位說明

項目 行為與限制
一般訊息 公頻、私聊、客服各有輸入；送出前去前後空白，空內容不送；按鈕或 Enter 可送，中文組字中的 Enter 不送
私聊對象 以玩家識別分開對話；切對象會換訊息，但私聊輸入是共用草稿，不是各對象獨立草稿
表情 私聊三種分類，點圖案加入輸入文字，仍需送出；不是即時發送的實體禮物
目錄 按玩家列表／好友列表才進 Mock 載入；提供載入、失敗重試與空列表。種子請求正常會成功，失敗需另備情境
好友 可直接加入／取消，按玩家識別去重；無邀請等待或對方同意步驟
封鎖 玩家卡確認後加入黑名單並關卡；取消不變。不自動刪好友或清聊天紀錄
檢舉 帶目標標題後由玩家輸入；送出把標題與內容加入客服訊息並清掉檢舉提示，不生成正式案件號
自動發送 非訪客可見入口；公頻與私聊分開保存開關、最多 100 字內容、可選貼圖與頻率。公頻單位分鐘、私聊單位天；輸入標示 1～999，但保存未完整阻擋越界值

無資料時顯示

欄位 呈現與界線
訊息輸入 空白或僅空白不送出。
目錄 支援空列表狀態；與載入錯誤分開，失敗可重試。
玩家身份、頭像、訊息時間 目前由展示資料提供；正式缺值呈現見 Q-11-001。
檢舉目標 一般客服無檢舉目標；帶入檢舉後仍需玩家輸入，不自動送出。

6. 狀態說明

狀態群組 規則
目錄 idle 尚未請求目錄。
目錄 loading 顯示載入，舊請求不可覆蓋新選擇。
目錄 loaded 顯示列表或空列表。
目錄 error 顯示失敗與重試。
好友／非好友 可直接加入取消；非好友也能進示範私聊。
封鎖／未封鎖 封鎖停用該對象私聊與查看資料；舊訊息保留。

原型限制與例外

私聊「遊戲點數」可接第 09 章；「贈送禮物」僅提示開發中。訊息沒有實際收件、送達／已讀、同步、附件上傳、重試或客服回覆服務。好友及黑名單為共用記憶體，關聊天保留、刷新重建；未完整依帳號隔離。

聊天訊息、輸入、已載入目錄及自動發送設定屬聊天視窗，主關閉再開會重建；切三個頻道時可保留當次局部狀態。與贈禮跨頁切換也會卸載聊天，不能承諾草稿與新訊息仍在。

7. 查詢、排序與分頁

按玩家／好友列表才發起 Mock 載入，非進入頁面即載入。已載入目錄為快照，可重新載入。未提供關鍵字、使用者排序或分頁；切頻道／私聊對象是對話切換。

8. 操作與跳轉

入口與返回

入口 傳入／預設 返回與交接
底部聊天 私聊頁與預設好友對話 主關閉回大廳
底部客服 線上客服 主關閉回大廳
聊天頭像／列表玩家 玩家卡資料、好友狀態 關玩家卡回底層聊天
玩家卡聊天 指定玩家識別、名稱及頭像 關玩家卡，切私聊，非好友亦可對話
玩家卡贈禮／轉點；私聊加號遊戲點數 接收者玩家 ID 切保險箱贈禮，沿用第 09 章；不自動返回原對話
玩家卡檢舉 檢舉標題及目標玩家 關玩家卡，切客服並顯示待填檢舉；不自動送出
自動發送 公頻／私聊各一份設定 保存仍留設定層，關閉回聊天

帶入資料

操作 帶入資訊
私聊／玩家卡 玩家識別、名稱與頭像。
贈禮 玩家 ID 帶至保險箱。
檢舉 目標玩家及標題，玩家補內容才送出。
訊息與自動發送設定 頻道、對象、文字或設定草稿；保存不啟動排程。

操作流程

私聊：開好友／玩家目錄 → 選對話或開玩家卡再按聊天 → 確認對象 → 輸入 → 送出 → 本機訊息追加且輸入清空。非好友入口建立示範直接對話，不要求先加好友。列表加好友立即更新共用關係；已載入的好友目錄是請求快照，重新載入再核對，不保證所有快照即時同步。

封鎖：玩家卡黑名單 → 確認 → 卡片關閉 → 該對象私聊輸入、表情、附加選單及送出停用。再點該玩家頭像會提示不可查看資料；既有訊息仍顯示，公共訊息未因封鎖被全面過濾。解除後可恢復這些本機入口。

客服：直接輸入問題，或由玩家卡帶檢舉目標 → 玩家補內容 → 按送出 → 追加客服訊息與提示，清輸入及本次檢舉標題。主關閉回大廳會清除導航帶入的檢舉草稿；同視窗切頻道可保留尚未送出的內容。

自動發送：開指定頻道設定 → 修改草稿 → 保存後更新該頻道設定並顯示已保存；取消／未保存關閉不提交修改。啟用圖示不會開始排程，也未執行公頻洗頻限制、每日上線或向所有聯絡人發送。

9. 頁面狀態

頁面狀態 呈現／未決範圍
載入中 好友／玩家目錄顯示載入。
查無資料 目錄有空列表，與請求失敗分開。
載入失敗 目錄支援錯誤及重試；正式訊息發送錯誤尚未定義。
局部失敗 目錄與訊息不同服務部分失敗的整合呈現見 Q-11-001。
無權限 訪客無自動發送入口；封鎖限制該對象操作，不是禁止整頁聊天。

12. User Story — QA 驗證者
