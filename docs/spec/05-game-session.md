## 1. 這個功能是什麼

玩家從大廳選擇遊戲，確認可用幣別後進入，並能離開返回大廳。活動銀幣使用與轉換銜接第 07 章；大廳分類與收藏的完整操作於第 04 章補寫。

進入不先扣一筆入場費，也不把錢包搬移至另一個遊戲帳戶。不同遊戲目前共用示意遊戲畫面，顯示所選遊戲的名稱、供應商與幣別；未提供實際下注、輸贏結算或逐局紀錄。

<a id="section-02"></a>

## 2. 這個功能不做什麼

| 不做的事 | 負責位置 |
|---|---|
| 大廳篩選及收藏 | 第 04 章大廳 |
| 卡片額度、合併與轉換計算 | 第 07 章獎勵卡 |
| 真實下注、遊戲數學及供應商結算 | 後續遊戲規格與串接契約 |


<a id="section-03"></a>

## 3. 名詞說明

| 名詞 | 定義與例子 |
|---|---|
| 支援幣別／可用幣別 | 遊戲支援金幣但餘額 0 時，支援數不等於可用數。 |
| 活動銀總額／遊戲可用 | 未啟用卡 5,000 可使總額為正，但遊戲可用仍為 0。 |
| 取消啟動／離開遊戲 | 前者留原大廳篩選；後者重建大廳並重置篩選。 |
| Mock 完成流水／正式結算 | 前者為原型操作，不證明逐局下注或供應商帳務完成。 |

## 5. 欄位說明

幣別可選必須同時符合「遊戲支援」與「該錢包可用額度大於 0」。金銀銅使用一般錢包，活動銀幣使用有效且使用中的卡片餘額；保險箱、未啟用卡片總額及活動金不納入可用選項。

| 狀態 | 顯示與操作 |
|---|---|
| 遊戲不支援 | 選項停用，說明此遊戲不支援此幣別；不是餘額不足 |
| 支援但一般錢包為 0 | 選項停用，提示目前不可用／餘額不足 |
| 支援但無可用活動銀 | 選項停用，提示需先啟用銀幣獎勵卡；已過期卡不構成可用卡 |
| 選定幣別有效 | 可按進入；入場後保留該幣別，遊戲室無切換錢包入口 |
| 活動銀卡已完成或失效 | 遊戲室卡片區顯示「本次獎勵卡已完成或失效」，Mock 流水按鈕停用，不自動退回大廳 |

### 無資料時顯示

| 欄位／資料 | 無資料時顯示與界線 |
|---|---|
| 遊戲名稱、供應商、圖示、RTP | 目前由所選遊戲提供；正式缺欄位呈現見 Q-05-001。 |
| 一般錢包／活動銀可用額度 | 真正為 0 時停用相應選項；不把資料載入失敗當餘額 0。 |
| 支援／可用數量 | 按當前遊戲與額度計算；可用為 0 時不能進入。 |
| 使用中活動銀卡 | 無有效卡時顯示「本次獎勵卡已完成或失效」並停用流水操作。 |

## 6. 狀態說明

代碼僅在已有原型列舉時對照，不鎖定正式後端 schema；各群組不可互相推導。

| 狀態群組 | 操作規則 |
|---|---|
| 不支援 | 不能選該幣別，原因與餘額不足不同 |
| 支援但不可用 | 一般餘額零或活動銀未啟用時停用 |
| 選中且可用 | 可進入；遊戲室無換幣入口 |
| 載入 | 品牌載入，無取消或重試 |
| 卡片已完成或失效 | 流水操作停用，不自動離開 |
| 離開 | 清除本次遊戲，不額外扣款或轉換 |

### 原型限制與例外

載入為原型展示，尚無逾時、供應商維護、斷線重連、進出遊戲帳務交接或正式失敗畫面。遊戲期間重新整理不恢復本次遊戲，保留的身份使玩家回到大廳；金融及卡片狀態依 [02.7](02-shared-rules.md#legacy-02-7) 重置。已取得的帳號、好友或卡片資料並不因此證明正式遊戲有持久化能力。

入場時只帶遊戲與幣別，活動銀卡由當下有效使用中卡取得；原型未固定一個正式的遊戲局與卡片結算關係。跨到期時刻及遊戲外狀態變動仍需獨立驗證，不以一般成功流程取代。

## 8. 操作與跳轉

### 入口、預設畫面與返回

| 入口／操作 | 帶入與預設 | 返回／交接 |
|---|---|---|
| 點大廳遊戲卡 | 開該遊戲啟動視窗，帶入遊戲及目前大廳幣別篩選 | 右上關閉或點背景取消，留原大廳及篩選 |
| 大廳未指定幣別（全部） | 初選遊戲第一種支援幣別；若不可用，改選清單中第一個可用幣別 | 全部不可用時進入按鈕停用 |
| 大廳指定幣別且遊戲支援 | 保留該幣別為選中，即使餘額不足也不自動換成別種 | 玩家可手動改選其他可用幣別；原選項不可用時不能進入 |
| 確認進入 | 保存這次遊戲及選中幣別，先顯示品牌載入，再顯示遊戲室 | 載入畫面尚無獨立取消或失敗重試入口 |
| 遊戲室離開 | 直接結束本次原型遊戲畫面，不另彈離開確認 | 回大廳；不自動停用卡、不額外轉換或退款 |
| 轉換結果「查看紀錄」 | 標記結果已讀、離開遊戲並開銀行紀錄 | 金融紀錄篩選規則見 [08.4.4](08-bank-and-promo.md#legacy-08-4-4) |

點遊戲卡時就寫入本機最近點選紀錄，因此取消啟動也已留下點選資料；目前沒有供玩家瀏覽的最近遊玩清單。遊戲室與大廳互相切換時大廳會重建，分類／供應商／幣別篩選及側欄開啟狀態回初始值，收藏偏好仍保存；不要把取消啟動與離開遊戲的返回結果混為一談。

### 帶入資料

| 操作 | 帶入資訊 |
|---|---|
| 點遊戲卡 | 遊戲識別、名稱、供應商、支援幣別及大廳幣別篩選 |
| 進入 | 選定遊戲及幣別；活動銀卡由當下有效使用中卡取得 |
| 離開 | 結束本次遊戲，無額外交易參數 |
| 轉換查看紀錄 | 結果已讀及目的地銀行紀錄；不再次入帳 |

### 操作流程

1. 在大廳選遊戲，於啟動視窗確認帶入幣別及可用額度。
2. 若目前不可用，可改選其他可用幣別；或取消，回銀行取得一般錢包餘額／至獎勵卡啟用卡片後再進入。沒有自動跳儲值的額外步驟。
3. 按進入，等待載入，核對遊戲室名稱及幣別。此時一般錢包與卡片不因入場而扣減。
4. 活動銀模式可使用 Mock 完成流水，轉換計算與卡片更新完整引用 07.5.4；其他幣別不顯示這項操作。
5. 按離開直接回大廳；若在轉換結果選查看紀錄，則改開銀行紀錄。單純確認／關閉結果留在遊戲室。

## 14. 這個功能需要的資料

| 能力 | 輸入 | 輸出 | 規則 |
|---|---|---|---|
| 啟動 | 遊戲及預設幣別、額度 | 選項可用性與選中結果 | 指定不可用幣別不自行換幣 |
| 進出遊戲 | 選定遊戲與幣別 | 遊戲室或重建大廳 | 不扣入場費、不另搬移錢包 |
| 活動銀轉換 | 有效使用中卡及原型完成操作 | 卡片、銀幣與紀錄結果 | 公式及一次入帳規則引用第 07 章 |

### 跨介面影響與保存

| 資料／事件 | 所需內容與影響 |
|---|---|
| 啟動 | 遊戲識別、名稱、供應商、支援幣別與四種額度；接收大廳可選的預設幣別 |
| 進入與離開 | 保留本次遊戲及幣別；離開清除本次遊戲；不以入場／離場自動新增金融紀錄 |
| 活動銀轉換 | 卡片、錢包、紀錄與通知依第 07 章同步；一般遊戲示意不產生真實遊戲紀錄 |
| 返回大廳 | 分開處理可保存收藏與會重建的篩選；轉換查看紀錄的導航目標不可丟失 |
