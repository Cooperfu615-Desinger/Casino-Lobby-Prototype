## 1. 這個功能是什麼

玩家查看身份與資產、找到遊戲，並進入會員、資產、活動及社交功能。大廳沒有關鍵字搜尋；遊戲卡依既有資料順序排列，左右箭頭為提示，不是翻頁按鈕。

<a id="section-02"></a>

## 2. 這個功能不做什麼

| 不做的事 | 負責位置 |
|---|---|
| 遊戲可用餘額與進入結算 | 第 05、07 章 |
| 付款與各功能內部操作 | 第 06～12 章 |
| 關鍵字搜尋與獨立最近遊玩清單 | 本版未提供，不因記錄最近點擊而新增 |

## 5. 欄位說明

四個篩選維度同時成立才顯示遊戲，維度內單選；選取立即生效，「查看 N 款遊戲」只收合抽屜。各類別／幣別／供應商旁數量取全遊戲資料的獨立計數，底部 N 才是多條件交集，不要求二者一致。

| 維度 | 可選內容與限制 |
|---|---|
| 收藏 | 全部或只看我的最愛，愛心可加入／移除；按愛心不觸發遊戲啟動 |
| 類別 | 全部、活動、老虎機、棋牌、電子、真人、Crash、魚機、樂透；無資料的非全部類別標 P2 並停用。活動名單為固定示範集合，不等於報名狀態 |
| 幣別 | 全部、金幣、銀幣、活動銀幣、銅幣；依遊戲支援篩選，不依玩家餘額隱藏遊戲 |
| 遊戲商 | 全部或資料中各供應商；與其他條件交集 |

### 無資料時顯示

| 欄位 | 呈現與界線 |
|---|---|
| 遊戲名稱、圖像、供應商、支援幣別 | 本機資料提供；正式缺值呈現見 Q-04-001。 |
| 收藏集合 | 無收藏且只看最愛時顯示「尚無我的最愛」。 |
| 結果與計數 | 合法交集為零顯示「找不到符合條件的遊戲」；非全部空類別標 P2 並停用。 |

## 6. 狀態說明

| 狀態群組 | 規則 |
|---|---|
| 篩選抽屜與子面板 | 收合保留條件；全部重設清條件。 |
| 收藏 | 已收藏／未收藏獨立於遊戲啟動。 |
| 無收藏／無交集 | 兩種空結果文字不同。 |
| 非全部且無資料的類別 | P2 停用，不新增功能入口。 |

### 原型限制與例外

未收藏時只看最愛顯示「尚無我的最愛」；有收藏但交集為零，或一般篩選無結果，顯示「找不到符合條件的遊戲」，回抽屜調整／全部重設。遊戲資料為本機列表，無遠端載入錯誤、關鍵字、排序或分頁流程。俱樂部與未可達導覽不在本版大廳開放範圍。

<a id="section-07"></a>

## 7. 查詢、排序與分頁

四個篩選維度立即交集，詳細選項見第 5 節。維度內單選；查看 N 款只收合。資料順序不重排、沒有關鍵字搜尋或分頁；列表橫向捲動，左右箭頭沒有翻頁事件。

## 8. 操作與跳轉

### 入口與返回

登入後或離開遊戲返回大廳。新建大廳初始顯示全部遊戲、全部供應商、全部幣別且不限收藏；篩選抽屜及設定收合。關閉一般功能回大廳會保留當次大廳篩選；進入遊戲後返回因大廳重建，篩選恢復預設，收藏仍依本機資料載入。

### 帶入資料

| 操作 | 帶入資訊 |
|---|---|
| 頂部與底部入口 | 依共用規則帶入預設頁籤；促銷圖示帶起始項。 |
| 點遊戲卡 | 遊戲識別與指定幣別篩選；收藏愛心不帶入啟動。 |
| 切篩選／重設 | 四維條件，重設不刪收藏。 |

### 操作流程

展開篩選 → 選維度與條件 → 立即核對符合數 → 查看結果收合 → 橫向捲動選卡 → 第 05 章選幣進入。收合選項只關子面板，收合抽屜或點背景保留條件；全部重設同時清除四項篩選，並不刪除收藏。

收藏流程為點愛心 → 樣式及本機清單更新 → 開只看我的最愛。若在收藏篩選中取消收藏，該卡立即退出結果。點遊戲卡即記錄最近遊戲，即使稍後取消啟動仍保留；這不是已完成投注紀錄。

## 9. 頁面狀態

| 頁面狀態 | 呈現／未決範圍 |
|---|---|
| 載入中 | 使用本機遊戲列表，無遠端列表載入畫面。 |
| 查無資料 | 分無收藏與條件交集為零，提供調整／重設。 |
| 載入失敗 | 尚無遠端錯誤畫面，見 Q-04-001。 |
| 局部失敗 | 遊戲列表與摘要部分取得失敗待定，見 Q-04-001。 |
| 無權限 | 未登入由啟動流程分流；停用 P2 類別不是權限錯誤。 |
