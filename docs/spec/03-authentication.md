## 1. 這個功能是什麼

讓未登入玩家選擇登入方式、建立身份或找回帳號的使用入口。已保存身份的玩家可在品牌載入後返回大廳；身份保存不等於金融資料保存，詳見 [02.7](02-shared-rules.md#legacy-02-7) 及 [06.7](06-member-profile.md#legacy-06-7)。

<a id="section-02"></a>

## 2. 這個功能不做什麼

| 不做的事 | 負責位置 |
|---|---|
| 正式帳號建立、密碼庫與第三方授權 | 身份服務與供應商契約 |
| 登入後個人資料修改與綁定 | 第 06 章 |
| 推廣關係與回饋入帳 | 後續推薦服務，本版只檢核格式 |


<a id="section-03"></a>

## 3. 名詞說明

| 名詞 | 定義與例子 |
|---|---|
| 註冊／登入 | 原型成功均建立展示身份，不代表正式帳號資料庫完成。 |
| 重發等待／有效期 | 60 秒是重發限制，不代表驗證碼只有效 60 秒。 |
| 註冊暱稱／個人資料暱稱 | 前者 2～12 字元，後者非空且最多 20 字元；不能直接統一。 |
| 註冊推廣碼 | 6 或 8 碼格式檢查，與個人邀請碼、銀行優惠碼的用途分開。 |


<a id="section-04"></a>

<a id="legacy-03-3"></a>

## 4. 畫面內容

首頁包括品牌、版本展示、七種登入入口與三種文件入口。帳號表單提供欄位錯誤、建立帳號及忘記密碼。註冊表單含身份欄位、選填推廣碼與文件閱讀狀態。各登入方式提供處理／成功畫面；處理階段不可概括為可隨時取消。

<a id="section-05"></a>

<a id="legacy-03-4"></a>

## 5. 欄位說明

| 欄位 | 原型限制與回饋 |
|---|---|
| 帳號 | 中英文及數字；不得空白或特殊符號，前後空白也不接受；半形長度 4～20，英數各算 1、中文字各算 2 |
| 帳號登入密碼 | 必填；一般 Mock 帳號不驗證真實密碼。若符合本機最近重設的帳號，須輸入該次新密碼 |
| 註冊暱稱 | 去除前後空白後 2～12 字元；輸入截至 12 字元 |
| 註冊／重設密碼 | 至少 6 字元，兩次一致；不新增複雜度或到期規則 |
| 註冊推廣碼 | 選填；輸入轉大寫、移除非英數並截至 8 碼；非空須為 6 或 8 碼。只檢查格式，未送出綁定或發獎；與優惠碼及邀請碼區分見 [02.5](02-shared-rules.md#legacy-02-5) |
| 註冊文件閱讀 | 必須開啟並按「我已閱讀並了解」才滿足註冊資格；「稍後再看」不完成閱讀。沒有滾到底才能按的條件 |
| 手機 | 09 開頭共 10 碼；輸入保留數字至 10 碼 |
| 驗證碼 | 6 碼數字，測試值為 123456；發送後 60 秒倒數才可重發。此為重發等待，未實作正式驗證碼有效期 |

### 無資料時顯示

| 欄位 | 呈現與界線 |
|---|---|
| 帳號、密碼、手機與驗證碼 | 必填或格式未滿時阻擋；錯誤留原步驟，不以預設帳號代填。 |
| 推廣碼 | 空白可註冊，非空才檢查 6／8 碼。 |
| 找回路徑與遮罩手機 | 目前是展示分流；正式不存在帳號或缺綁定資料見 Q-03-001。 |

## 6. 狀態說明

| 狀態群組 | 規則 |
|---|---|
| 帳號／註冊 | 表單 → 處理 → 成功；處理與成功沒有一般表單關閉。 |
| 手機 | 號碼 → 驗證 → 成功；號碼與驗證階段可關閉或返回修改。 |
| 第三方 | 連線 → 授權確認 → 允許或取消；不是真實授權。 |
| 找回 | 一般手機重設、line888 社群引導、unbound888 客服展示分流。 |

### 原型限制與例外

登入、註冊與第三方處理／成功階段不提供一般表單關閉；手機在號碼／驗證階段才可關閉。找回流程在查詢、重設或社群連線處理時限制關閉。背景點擊與 ESC 不是本章共用關閉能力。

一般找回流程展示固定遮罩手機，並未真正查詢帳號是否存在或已綁定。只有 line888 與 unbound888 分流，不能據此推定其他帳號均符合正式找回資格。本機只保存最近一次重設的帳密供示範；註冊密碼不形成正式憑證庫。正式錯誤密碼、簡訊失敗、第三方拒絕／逾時及帳號凍結等仍需服務規則。

## 7. 查詢、排序與分頁

## 8. 操作與跳轉

### 入口與返回

| 入口 | 初始畫面與操作 | 返回／完成 |
|---|---|---|
| 開啟 APP | 品牌載入；檢查本機身份 | 有可讀身份進大廳，無身份進登入首頁 |
| 帳號 | 空密碼表單，可切建立帳號／忘記密碼 | 表單關閉回首頁；登入成功進大廳 |
| 建立帳號 | 從帳號登入開啟註冊表單 | 關閉回帳號登入並清密碼；成功直接進大廳 |
| 遊客 | 直接顯示處理及成功階段 | 建立隨機訪客身份進大廳，不經註冊表單 |
| 手機 | 手機號碼 → 驗證碼 | 表單階段可關閉；驗證頁可返回修改手機 |
| Facebook／LINE／Apple／Google | 連線示意 → 授權確認 | 確認階段取消回首頁；允許後登入示範身份 |
| 首頁三種文件 | 使用者規章／隱私權政策／服務條款 | 閱讀後關閉回登入首頁 |
| 忘記密碼 | 帶入已填帳號 | 返回會員登入會帶回帳號並清空密碼；關閉回首頁 |

### 帶入資料

| 操作 | 帶入資訊 |
|---|---|
| 帳號／註冊 | 帳號、密碼；註冊另帶暱稱及閱讀確認，推廣碼未建立關係。 |
| 手機 | 號碼、驗證碼及驗證結果。 |
| 第三方 | 提供者與示範允許／取消結果。 |
| 找回與返回 | 帶入帳號，重設後返回帳號登入時密碼清空。 |

### 操作流程

| 流程 | 玩家步驟與更新 |
|---|---|
| 帳號登入 | 填帳號密碼 → 送出 → 格式／本機重設密碼檢查 → 處理 → 成功 → 大廳。錯誤留表單供修正 |
| 建立帳號 | 填欄位 → 閱讀並確認文件 → 符合條件後註冊 → 處理與成功 → 以帳號和暱稱登入大廳；無帳號重複查詢或正式帳號建立 |
| 手機登入 | 合法手機發送 → 輸入測試碼 → 驗證 → 成功進大廳；錯碼留驗證頁；重發清空驗證碼並重啟倒數 |
| 第三方登入 | 選提供者 → 等待確認頁 → 取消或允許 → 成功登入固定示範身份；沒有真實帳號挑選或權限授權 |
| 一般帳號找回 | 輸入帳號 → 展示遮罩手機 → 發送 → 驗證 123456 → 新密碼與確認 → 重設成功 → 返回帳號登入。成功不自動登入 |
| 社群帳號找回 | 測試帳號 line888 進 LINE 引導 → 連線 → 允許 → 登入；確認取消退回社群引導 |
| 未綁手機找回 | 測試帳號 unbound888 → 未綁定說明 → 客服協助展示 → 返回登入；沒有建立客服案件 |

## 9. 頁面狀態

| 頁面狀態 | 呈現／未決範圍 |
|---|---|

| 無權限 | 未登入顯示登入頁；凍結或停權不是現有分流，見 Q-03-001。 |

## 14. 這個功能需要的資料

| 能力 | 輸入 | 輸出 | 規則 |
|---|---|---|---|
| 身份建立 | 登入方式、帳號／手機、必要欄位 | 身份結果或錯誤 | 原型種子不證明多帳號隔離。 |
| 找回 | 帳號、可用途徑、驗證及新密碼 | 重設結果與返回帳號 | 成功不自動登入，除社群示範路徑。 |

### 跨介面影響與保存

需要登入方式、帳號／手機、註冊暱稱、身份結果及必要錯誤；找回需帳號可用途徑、遮罩聯絡資料、驗證結果與重設結果。原型成功建立個人摘要及 Mock 資產；一般會員共用示範玩家 ID，不能當正式多帳號隔離證據。註冊暱稱為 2～12 字元，登入後基本資料編輯則為非空、最多 20 字元；兩個入口目前限制不同，後續調整須一起核對。刷新恢復已保存個人資訊，但錢包與 VIP 指標重建；登出後重新登入會重新建立示範身份資料，不等於載入完整會員檔案。
