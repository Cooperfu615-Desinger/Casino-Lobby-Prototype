## 1. 這個功能是什麼

信箱供閱讀營運公告、系統通知及領取附件；設定供調整本機體驗、查閱規章、解除封鎖與登出。兩項功能共列本章，但入口、資料及生命週期各自獨立。

<a id="section-02"></a>

## 2. 這個功能不做什麼

| 不做的事 | 負責位置 |
|---|---|
| 獎勵卡管理與 VIP 儲值 | 第 06、07 章 |
| 完整翻譯、推播訂閱與正式遊戲音訊 | 後續對應服務 |
| 信箱核銷、還原與到期處理 | 正式信箱服務，本版未完成 |


<a id="section-03"></a>

## 3. 名詞說明

| 名詞 | 定義與例子 |
|---|---|
| 選中／已讀 | 自動選第一封可顯示詳情，但需主動點信才標已讀。 |
| 附件已領／正式核銷 | 同視窗已領停用；重開恢復種子是原型缺口，不能作正式領取規則。 |
| 語言偏好／翻譯 | 保存 English 不代表正文已翻譯。 |
| 推播開關／系統訂閱 | 原型只改選單狀態，不請求通知權限。 |

## 6. 狀態說明

| 狀態群組 | 規則 |
|---|---|
| 信件未讀／已讀 | 自動選中與已讀分開；主動點選才更新。 |
| 附件可領／處理／已領 | 約一秒處理，同視窗不重領；主關閉重開缺口仍在。 |
| 語言可用／即將開放 | 繁中、English、日本語可選，其餘停用。 |
| 黑名單有資料／空 | 解除直接生效，清單與數量同步。 |

### 原型限制與例外

信件內容及獎勵都是示範，未提供真實收信、附件核銷或服務錯誤頁。推播未接系統通知；語言只存偏好；規章是展示文本，正式版本與同意保存另定。黑名單解除只恢復原型可達操作，未證明服務端封鎖解除。這些限制須隨相關修正工作單一起核對。

<a id="section-07"></a>

## 7. 查詢、排序與分頁

信箱按營運公告／系統通知分類，切分類自動選第一封但不標已讀。沒有關鍵字、日期查詢、排序切換或分頁；黑名單同樣無查詢分頁。

## 8. 操作與跳轉

### 入口與返回

底部信箱預設營運公告並選取第一封，左列表右詳情；主關閉回大廳。頂部設定開選單，點背景或設定鈕收合；切語言、規章或黑名單時先關選單再開對應視窗，關視窗回大廳。登出直接回登入首頁，沒有確認對話框。

### 帶入資料

| 操作 | 帶入資訊 |
|---|---|
| 讀信／刪信／領附件 | 信件識別、分類與附件狀態。 |
| 偏好 | 音樂、音效、語言、日夜或當次推播值。 |
| 解除封鎖 | 目標玩家識別，共用黑名單同步。 |
| 登出 | 清除當前身份，沒有整體資料清空承諾。 |

### 信箱操作與狀態

選營運／系統分類 → 自動選第一封詳情 → 主動點信件才標已讀。**初始選中、切分類或刪除後自動選中下一封，不會自動標已讀**；詳情可見與已讀狀態不能混為一談。

附件：在有附件的信件按領取 → 約 1 秒處理 → 同視窗標已領、更新金幣及餘額動畫。所有附件目前固定加 50,000 一般金幣，沒有按信件內容解析不同獎品，也不新增金融紀錄。處理期間其他附件不能同時領取；正式重複請求、離頁及餘額競態尚無保證。

刪除：列表垃圾桶直接刪除並提示，不二次確認；即使附件未領也可刪。刪除選中信件時改選同類第一封，沒有則清空；分類數量與未讀數同步。沒有全部已讀、批次領取、刪除還原或正式到期處理。

**保存限制：**分類、信件、已讀、刪除與已領集合都是信箱局部狀態。主關閉再開即回種子信件且附件可再次領取，但已加的金幣仍在當次錢包；這是原型缺口，不是正式可重領規則。領取中的關閉／刪除未完整封鎖，延遲操作仍可能更新錢包，需於正式流程補驗證。

### 設定操作與狀態

| 操作 | 結果與保存 |
|---|---|
| 背景音樂 | 即時開關循環播放；瀏覽器自動播放限制可能需一次互動，開關值不等於已出聲 |
| 遊戲音效 | 控制既有音效播放入口，不代表所有正式遊戲音訊均接入 |
| 日夜 | 即時更新大廳與相關共用外觀；沒有依時段自動切換 |
| 推播通知 | 只改選單當次開關；收合再開回預設開啟，不請求系統權限或訂閱服務 |
| 語言 | 選可用語言即保存並關閉；選相同語言只關閉。原型文字仍繁中；停用語言不可選 |
| 使用者規章 | 唯讀文件總覽，可切文件並關閉／我知道了；不是重新簽署註冊同意 |
| 黑名單解除 | 按解除立即移除並提示，數量同步；無二次確認；清空後顯示空列表，私聊限制同步解除 |
| 登出 | 清當前身份及其本機保存，返回登入；不概括清除所有功能共用狀態或本機偏好 |

音樂、音效、語言與日夜存本機，收合、刷新及登出可保留，未依帳號分區。黑名單是社交記憶體，刷新重建；不能從登出推定其他共用狀態均已清理，詳見 [02.7](02-shared-rules.md#legacy-02-7)。

## 9. 頁面狀態

| 頁面狀態 | 呈現／未決範圍 |
|---|---|
| 載入中 | 附件有處理階段，信件資料不是遠端載入。 |
| 查無資料 | 信箱無信清選取；黑名單空清單。 |
| 載入失敗 | 信件與正式核銷無服務錯誤頁，見 Q-12-001。 |
| 局部失敗 | 信件可讀但附件或偏好服務失敗的呈現待定。 |
| 無權限 | 推播未請求系統權限；不可將偏好開關當成授權成功。 |

## 14. 這個功能需要的資料

| 能力 | 輸入 | 輸出 | 規則 |
|---|---|---|---|
| 信箱 | 信件識別、分類、已讀、附件 | 顯示、刪除或領取結果 | 原型重開重領是缺口。 |
| 偏好 | 選定設定值 | 本機保存結果 | 推播、音訊與語言能力各自分開。 |
| 黑名單／登出 | 玩家識別或當前身份 | 解除關係或退出身份 | 不清所有共用狀態。 |

### 跨介面影響與保存

信件需要識別、類型、日期、標題、正文、已讀、附件及領取結果；正式領取須使資格、獎勵與帳務一致，目前不具備該服務。設定需要偏好值及保存結果；黑名單共用玩家識別與關係。信箱獎勵更新一般金錢包與摘要，不產生獎勵卡或 VIP 儲值指標。
