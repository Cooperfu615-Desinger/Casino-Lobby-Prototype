1. 這個功能是什麼

玩家用途、身份與可操作範圍。

待填。

2. 這個功能不做什麼

表格：不做的事、負責文件。只列容易誤認的責任。

待填。

3. 名詞說明

引用共用規則；近似名詞分開並舉例。

待填。

4. 畫面內容

由上至下列區塊與內容，不填精細視覺數值。

待填。

5. 欄位說明

表格：欄位、內容／限制、無資料時顯示。未定義須明示並連到問題。

待填。

6. 狀態說明

每組狀態分表：原型代碼、顯示、意思；期限與資格另表，不混用。

待填。

7. 查詢、排序與分頁

篩選型態、觸發、排序、分頁；不適用須說明。

待填。

8. 操作與跳轉

表格：操作位置、前提、目的地／結果、帶入資料、返回與保留。

待填。

9. 頁面狀態

逐列檢查載入中、查無資料、載入失敗、局部失敗、無權限，區分現況與未決。

待填。

10. User Story — 玩家

每則一欄表：US-U-章號-流水號、身為玩家我要、GIVEN、WHEN、THEN。

待填。

11. User Story — 開發人員

每則一欄表：US-D-章號-流水號、身為開發人員我要、GIVEN、WHEN、THEN。

待填。

12. User Story — QA 驗證者

每則一欄表：US-Q-章號-流水號、身為 QA 我要、GIVEN、WHEN、THEN。

待填。

13. 驗收標準

表格：既有 AC 編號、主題、Given／When／Then；引用情境與證據位置。

待填。

14. 這個功能需要的資料

依能力列輸入、輸出、規則；涵蓋跨頁更新及保存，不定 API。

待填。

15. 待確認事項

分待產品決策與待外部輸入；編號、問題、影響／等待對象、狀態。

待填。

16. 版本沿革

表格：版本、日期、內容；保留歷史。

待填。

17. 交付檢查表

表格：檢查面、可回答是否的完成條件、確認；不等於操作驗收。

待填。
