# 銀行優惠碼 — 原型確認版

## 範圍與入口

- 大廳「銀行」→「優惠」。保留儲值、紀錄頁；原優惠購買卡片隱藏，不刪除方案資料。
- 優惠碼為營運取得的 8 碼英數字，與個人邀請碼分開。前台不製作後台產碼功能。
- 輸入忽略前後空白與英文大小寫，不接受其他字元或錯誤長度。
- 訪客可瀏覽，但需註冊／登入一般會員才能兌換。

## 操作與狀態

1. 輸入優惠碼，點「兌換」先檢查資格、格式、存在性、生效期限與領取狀態。
2. 成功開啟「確認優惠碼兌換」彈窗，顯示商品名稱、數量、幣別、優惠碼可兌換期限與商品使用期限；活動銀另顯示流水與轉換上限。
3. 取消或關閉預覽不領取、不使用優惠碼。
4. 點「確認領取」重新檢查後立即發放，無等待期；顯示成功結果與銀行紀錄。
5. 同一會員同碼限領一次，包含連點防重複。關閉銀行／切頁保留，重新整理重置。
6. 格式錯誤、不存在、尚未生效、已過期、已領取或無法發放，皆顯示原因且不入帳。

## 獎勵去向

| 類別 | 確認領取結果 | 本次邊界 |
|---|---|---|
| 儲值銀幣 | 增加銀幣錢包，Header 與個人資訊同步 | 不計作付費儲值、不增加 VIP 儲值指標 |
| 銅幣 | 增加銅幣錢包 | 不影響其他幣別 |
| 活動銀幣 | 新增一張未啟用獎勵卡，個人資訊與獎勵卡概覽同步增加 | 沿用既有啟用、合併、流水與轉換；不占每日任務領取資格 |
| 活動金幣 | 增加活動金額度，個人資訊與獎勵卡概覽同步 | 已確認僅入帳與顯示；不新增遊戲使用、流水轉換或到期回收 |

每次成功兌換新增銀行「紀錄 → 獎勵」成功紀錄，記載優惠碼、商品、幣別與數量。刪除或合併活動銀卡不恢復優惠碼領取資格。

## Mock 範例與待確認

- 測試碼置於優惠頁可展開的原型測試區。各碼只對應一種商品，商品由優惠碼決定，不由玩家任選幣別。
- 正常示範碼期限為 2026 年；另提供過期與尚未開始範例。
- 活動銀範例：5,000、流水 50,000、轉換上限 5,000、使用期限 2027/01/31。這些是可調整的示範資料，不是正式營運規則。

- 會員以登入來源＋帳號區分領取狀態，僅本機記憶體保存，無後端原子交易／跨裝置防重複保證。

## 驗收重點

- 四種獎勵各自入正確位置，不改其他餘額。
- 預覽取消無紀錄、無入帳；重複碼、過期碼、未開始碼、不存在碼不入帳。
- 關閉銀行、切換分頁後不可重領；活動銀卡刪除／合併不重開優惠資格。
- 1280 × 720 畫布內預覽內容與確認／取消按鈕可完整操作。
